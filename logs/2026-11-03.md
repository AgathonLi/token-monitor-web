## 模型行厂商前缀归一、Ling 图标与 Grok 渠道合并

用户先确认合并 `deepseek/deepseek-v4.1-flash`、`z-ai/glm-5.3-flash`，随后要求把「去掉厂商前缀、只显示模型名」做成通用规则，并修复 `inclusionai/ling-3.1-flash-1019:free` 的灰色字母占位图标；同时询问 `grok-4.7-build` 与 `grok-4.7` 是否应合并。整改方案经独立子代理审阅（结论：有条件通过），按审阅意见修正后实施。仅改独立网页的展示层，未修改 Hub、采集器、Worker、Limits 或桌面配置。

### 修改

- `index.html` 新增 `displayModelId`：在任何别名解析和 1% 阈值判断之前，用大小写不敏感的 `^(?:[a-z0-9][a-z0-9._-]*\/)+([^/].*)$` 去掉模型 ID 开头的全部厂商/组织命名空间；`foo/`、`foo//bar`、`/bar`、`///` 等畸形或空段 ID 回退原文。`models` 与 `modelCosts` 分别归一后独立累加，周期总数不变，Hub 原始 payload 不改。
- 新增 `ling` 厂商：品牌蓝 `#144DFF`、24×24 单色 Ling SVG（LobeHub 图标库，MIT），`modelVendorFor` 使用 `^ling(?:[-.]|$)`，不误伤 `kling-*`。主列表 16px、折叠标签 14px 均使用同一内联图标，不新增外部请求。
- `MODEL_DISPLAY_ALIASES` 新增精确映射 `"grok-4.7-build": "grok-4.7"`。依据：`grok-4.7` 是 xAI 公开 API 的标准 ID；`grok-4.7-build` 最可能是 Grok Build 渠道对同一 Grok 4.7 的命名。真正独立计价的是 `grok-4.7-build-fast`（同模型、2 倍价格、仅 Grok Build/Cursor），因此**不**合并、也不引入通用后缀剥离。
- `tests/model-display.test.cjs` 新增 5 项回归：单段/多段前缀合并与 token/费用守恒、畸形 ID 回退、前缀与既有别名复合、Ling 裸名与图标及 `kling`/`billing` 负向、Grok 渠道合并且 `-build-fast` 保持独立。
