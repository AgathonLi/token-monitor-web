# 2026-08-30 开发日志

会话从 Hermes Scratch 迁入本项目。此前在同一对话里完成 Cloudflare Hub 部署，再做网页看板。

## 背景（不在本仓库）

- 桌面应用：Token Monitor；Hub：Cloudflare Worker `token-monitor-hub`
- Fork：`AgathonLi/token-monitor`（上游 `Javis603/token-monitor`），Workers Builds 根目录 `worker/`
- 浏览器直接打开 Hub 根路径会 `401 unauthorized`，这是密钥已生效；`503 secret_required` 才是线上没读到 Secret
- 一键 Deploy to Cloudflare 会孤立副本、不跟上游；正确做法是 Builds 连 fork + Sync fork

## 本仓库决定

- 方案 B：独立单页 HTML，不改 fork
- 密钥存在浏览器 `localStorage`（`tm-dash-v1`），用 `Authorization` 头，不用 `?secret=` 当默认
- 界面按用户提供的桌面小组件截图做成浅色：主页 / 工具 / 额度 / 模型 / 趋势，DAY/MONTH/TOTAL
- 电脑与手机同一套布局，桌面居中约 430px，避免两套视觉分叉后再对不齐截图

## 已修问题

- `.gate { display: grid }` 盖过 `hidden`，连上后登录卡仍铺满 → 增加 `[hidden] { display: none !important }`
- Python `http.server` 日志里的 `favicon.ico` 404 与 `GET / 304` 不代表 Hub 失败；Hub 请求不经过这台本地服务器
- 打开方式必须是 `http://127.0.0.1:8765/`，改代码后要 Ctrl+F5
